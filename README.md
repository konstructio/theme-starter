# theme-starter

The smallest possible theme theme: a static frontend the platform builds
with Cloud Native Buildpacks and serves inside your organization.

- `static/theme.js` — the whole client contract: auth handshake + API calls. Copy it, keep it.
- `static/index.html` — a bare rendering of zones and apps. Replace with your metaphor.
- `THEME.md` — your theme's declaration: capabilities and vocabulary.

Authoring spec (sufficient for humans or AI assistants):
https://konstruct.civo.com/docs/konduit/creating-a-theme
